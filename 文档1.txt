车载智能监测与控制系统完整实现文档
一、项目整体概述
本车载智能监测与控制系统以 STM32F407VGT6 主控单片机为核心，搭载 FreeRTOS 实时操作系统，实现车辆行驶状态监测、环境数据采集、车速检测、震动防撞预警、声光报警、车载屏幕可视化显示、数据本地存储等全套车载智能化功能。
系统可实时采集车辆姿态、行车环境温度、湿度、车速、车身震动数据，智能判断车辆超速、剧烈颠簸、碰撞预警、异常怠速等行车状态，并通过车载屏幕实时刷新数据、声光模块提示异常，同时将行车日志存储至本地 Flash，支持事后数据追溯。整套系统稳定性强、实时性高、抗车载电源干扰能力优异，可适配家用小车、工程车载设备、智能巡检车辆等场景。
二、系统硬件整体方案
2.1 核心硬件选型（具体型号+参数）
•	主控单片机：STM32F407VGT6，Cortex-M4内核，主频168MHz，1MB片内Flash、192KB RAM，支持FPU浮点运算，满足多传感器并行采集与实时算法运算，工业级抗干扰，适配车载复杂电气环境。
•	姿态与震动检测模块：MPU6050六轴陀螺仪加速度传感器，集成三轴加速度+三轴陀螺仪，IIC通信，可精准采集车身倾角、震动幅度、姿态变化，用于防撞、颠簸、姿态异常判断。
•	温湿度采集模块：DHT11数字温湿度传感器，单总线通信，采集车载环境温度、湿度数据，实时监测车内设备工作环境。
•	车速检测模块：霍尔测速传感器（型号JY-110），磁吸感应测速，适配车轮转速采集，脉冲信号输入单片机，换算实时车速。
•	声光报警模块：5V有源蜂鸣器+0805高亮LED，分级报警，超速、震动异常、姿态异常时触发不同提示逻辑。
•	人机交互显示模块：2.8寸 SPI 串口TFT触控液晶屏，分辨率240*320，搭载LVGL图形界面，实时显示车速、温湿度、车身姿态、系统状态、告警记录。
•	数据存储模块：W25Q128JV SPI Flash（16M字节），持久化存储行车日志、告警记录、车辆状态数据，断电数据不丢失，支持数据回溯分析。
•	车载供电模块：DC12V转5V车载降压模块，带防反接、过压、过流保护，适配车载12V电源输入，为整套系统稳定供电。

三、系统软件整体架构
3.1 软件运行环境
•	开发平台：Keil MDK5
•	内核系统：FreeRTOS V9.0 实时操作系统
•	库函数：STM32 HAL库
•	图形库：LVGL 8.2 轻量化图形库
•	编译环境：ARM-CAC
3.2 FreeRTOS多任务架构设计
系统采用多任务分层解耦设计，各功能独立任务运行，互不阻塞，保障车载数据高频采集、实时告警、界面刷新同步进行，杜绝车载环境下系统卡顿、数据丢失问题。
•	车速采集任务：通过外部中断统计车轮脉冲数，定时换算实时车速，判断超速状态。
•	姿态震动采集任务：周期性读取MPU6050数据，解算车身倾角、震动幅值，识别颠簸、碰撞、车身倾斜异常。
•	温湿度采集任务：定时采集车内环境温湿度，更新系统环境参数。
•	告警判断任务：汇总车速、姿态、震动数据，智能判断异常状态，触发声光报警。
•	行车日志存储任务：将车速、告警信息、时间、姿态数据写入Flash，实现行车数据留存。
•	LVGL界面刷新任务：实时刷新屏幕数据、状态图标、告警提示界面。
3.3 核心业务逻辑流程
1.	系统初始化：上电后依次初始化系统时钟、GPIO、IIC、SPI、中断、传感器、Flash、LVGL界面，加载历史行车日志。
2.	数据实时采集：并行采集车速、车身姿态、震动、车内温湿度数据。
3.	智能状态判断：系统内置阈值，判断车辆是否超速、是否剧烈颠簸、是否车身倾斜、是否存在碰撞冲击。
4.	异常告警响应：检测到异常后，LED闪烁、蜂鸣器分级报警，屏幕弹窗提示异常类型。
5.	数据持久化存储：正常行车数据、所有告警事件自动写入Flash，支持断电保存、事后查询。
6.	界面实时更新：屏幕动态显示实时车速、温湿度、车身姿态、系统状态、告警记录。
四、系统核心功能详细实现
4.1 车速监测与超速告警功能
通过霍尔传感器捕捉车轮转动脉冲，单片机外部中断计数，结合定时周期计算车轮转速，换算车辆实时行驶速度。系统预设安全车速阈值，当实时车速超过阈值时，立即触发声光告警，屏幕弹出超速提示，同时记录超速时间与车速数据至行车日志。低速行驶、怠速状态系统自动识别，无告警干扰。
4.2 车身姿态与防撞震动监测功能
利用MPU6050六轴传感器实时采集加速度与陀螺仪数据，通过姿态解算算法得到车身俯仰角、横滚角，同时采集瞬时震动幅值。可精准识别车辆高速颠簸、路面剧烈震动、车身倾斜过大、轻微碰撞冲击等状态。当数据超出安全阈值时，系统立即触发预警，有效辅助行车安全监测，避免因路况异常、车身姿态异常导致的行车隐患。
4.3 车内环境温湿度监测功能
DHT11传感器周期性采集车内环境温度与湿度，数据实时显示在车载屏幕。可监测车载设备工作环境温度，避免高温、潮湿环境导致车载电子设备故障，为车载设备稳定运行提供环境数据支撑。
4.4 分级声光告警功能
系统设计分级告警逻辑：普通异常（轻微超速、小幅颠簸）为短蜂鸣提示；严重异常（严重超速、剧烈震动、车身倾斜、碰撞冲击）为连续蜂鸣+LED高频闪烁，区分故障等级，便于驾驶员快速识别行车异常程度。
4.5 行车日志存储与数据回溯功能
所有行车数据、异常告警事件、时间戳均通过W25Q128 Flash持久化存储，支持循环覆盖存储，避免存储溢出。设备断电后数据不丢失，可通过系统界面查看历史行车记录与告警记录，实现行车状态回溯、故障分析。
4.6 LVGL车载可视化界面功能
搭载LVGL图形界面，界面包含车速显示区、温湿度显示区、车身姿态数据区、系统状态栏、告警记录查询界面。界面刷新流畅，数据实时同步，人机交互直观，满足车载设备可视化使用需求。
五、关键技术与优化方案
5.1 车载抗干扰优化
车载电源存在电压波动、电磁干扰等问题，系统软件增加多次数据采样滤波、均值滤波算法，过滤传感器跳变数据；硬件搭配稳压滤波电路，避免电压波动导致系统重启、数据异常，大幅提升车载环境适应性。
5.2 多任务实时性优化
基于FreeRTOS优先级分层设计，数据采集、异常判断任务优先级最高，界面刷新、日志存储任务优先级次之，保证行车安全相关功能优先响应，杜绝系统延迟、卡顿。
5.3 传感器数据防抖滤波优化
对车速脉冲、姿态数据、温湿度数据采用软件滤波算法，去除偶然干扰数据，保证采集数据平稳精准，避免误告警、误判断问题。
5.4 Flash存储优化
采用按需擦写、分页存储、循环覆盖机制，减少Flash擦写次数，降低硬件损耗，延长设备使用寿命，同时保证行车日志完整可靠。

•	软件可行性：基于成熟FreeRTOS系统与HAL库开发，架构稳定，功能模块化，便于后期拓展胎压监测、GPS定位、蓝牙上传等功能。
•	实用性：系统覆盖车速监测、防撞预警、环境监测、数据记录、可视化显示，完全满足智能车载安全监测需求，可直接落地应用。

/*************************************************
* 车速中断计数：霍尔脉冲计数
*************************************************/
void EXTI1_IRQHandler(void)
{
    if(EXTI_GetITStatus(EXTI_Line1) != RESET)
    {
        g_speed_cnt ++;
        EXTI_ClearITPendingBit(EXTI_Line1);
    }
}

/*************************************************
* 车速采集任务：定时计算车速
*************************************************/
void Speed_Scan_Task(void *pvParameters)
{
    uint32_t last_cnt = 0;
    while(1)
    {
        last_cnt = g_speed_cnt;
        vTaskDelay(pdMS_TO_TICKS(1000));
        
        // 简易车速换算
        g_car_status.speed = (g_speed_cnt - last_cnt) * 0.12f;
        if(g_car_status.speed > SPEED_OVER_THRESHOLD)
        {
            g_car_status.speed_over_flag = 1;
        }
        else
        {
            g_car_status.speed_over_flag = 0;
        }
    }
}

/*************************************************
* 姿态震动采集任务 MPU6050
*************************************************/
void Attitude_Scan_Task(void *pvParameters)
{
    float ax,ay,az;
    float gx,gy,gz;
    while(1)
    {
        // 读取六轴数据
        MPU6050_Read_Acc(&ax,&ay,&az);
        MPU6050_Read_Gyro(&gx,&gy,&gz);

        // 姿态解算
        MPU6050_Get_Angle(&g_car_status.pitch,&g_car_status.roll);

        // 计算震动幅值
        g_car_status.shake_val = (uint16_t)(fabs(ax) + fabs(ay) + fabs(az)) * 100;

        // 颠簸/碰撞判断
        if(g_car_status.shake_val > SHAKE_THRESHOLD)
        {
            g_car_status.shake_err_flag = 1;
        }
        else
        {
            g_car_status.shake_err_flag = 0;
        }

        // 车身倾斜判断
        if(fabs(g_car_status.pitch) > ANGLE_THRESHOLD || fabs(g_car_status.roll) > ANGLE_THRESHOLD)
        {
            g_car_status.angle_err_flag = 1;
        }
        else
        {
            g_car_status.angle_err_flag = 0;
        }

        vTaskDelay(pdMS_TO_TICKS(50));
    }
}

/*************************************************
* 温湿度采集任务 DHT11
*************************************************/
void Environment_Scan_Task(void *pvParameters)
{
    while(1)
    {
        DHT11_Read_Data(&g_car_status.temp,&g_car_status.humi);
        vTaskDelay(pdMS_TO_TICKS(1000));
    }
}

/*************************************************
* 告警判断任务：分级报警
*************************************************/
void Alarm_Judge_Task(void *pvParameters)
{
    while(1)
    {
        // 严重告警
        if(g_car_status.speed_over_flag || g_car_status.shake_err_flag)
        {
            Alarm_Level_Set(2);
            Save_Car_Log();
        }
        // 轻微姿态异常
        else if(g_car_status.angle_err_flag)
        {
            Alarm_Level_Set(1);
        }
        else
        {
            Alarm_Level_Set(0);
        }

        vTaskDelay(pdMS_TO_TICKS(100));
    }
}

/*************************************************
* 行车日志存储任务
*************************************************/
void Log_Save_Task(void *pvParameters)
{
    CarLog_t log_buf;
    while(1)
    {
        if(xQueueReceive(xLogQueue,&log_buf,portMAX_DELAY) == pdPASS)
        {
            // 循环地址存储
            uint32_t addr = 0x20000 + (log_buf.time_stamp % 1024) * sizeof(CarLog_t);
            W25QXX_WriteBuffer((uint8_t *)&log_buf, addr, sizeof(CarLog_t));
        }
    }
}

/*************************************************
* LVGL界面刷新任务
*************************************************/
void LVGL_UI_Task(void *pvParameters)
{
    while(1)
    {
        lv_timer_handler();
        UI_Update_Data();
        vTaskDelay(pdMS_TO_TICKS(5));
    }
}

/*************************************************
* 告警分级控制
* level 0:关闭 1:轻微 2:严重
*************************************************/
void Alarm_Level_Set(uint8_t level)
{
    if(level == 0)
    {
        HAL_GPIO_WritePin(ALARM_LED_PORT,ALARM_LED_PIN,GPIO_PIN_RESET);
        HAL_GPIO_WritePin(BEEP_PORT,BEEP_PIN,GPIO_PIN_RESET);
    }
    else if(level == 1)
    {
        HAL_GPIO_TogglePin(ALARM_LED_PORT,ALARM_LED_PIN);
        HAL_GPIO_WritePin(BEEP_PORT,BEEP_PIN,GPIO_PIN_SET);
        vTaskDelay(pdMS_TO_TICKS(50));
        HAL_GPIO_WritePin(BEEP_PORT,BEEP_PIN,GPIO_PIN_RESET);
    }
    else if(level == 2)
    {
        HAL_GPIO_WritePin(ALARM_LED_PORT,ALARM_LED_PIN,GPIO_PIN_SET);
        HAL_GPIO_WritePin(BEEP_PORT,BEEP_PIN,GPIO_PIN_SET);
    }
}

{

    log.temp = g_car_status.temp;
    log.pitch = g_car_status.pitch;
    log.roll = g_car_status.roll;

    else if(g_car_status.angle_err_flag)  log.alarm_type = 3;

}

8.4 配套底层驱动说明
本工程代码依赖以下通用开源成熟驱动（车载项目标准适配）：
•	mpu6050.c/h：六轴数据读取、姿态解算、角度计算，适配IIC1，支持车身倾角、震动采集。
•	dht11.c/h：单总线温湿度读取，软件时序适配，数据均值滤波。
•	w25qxx.c/h：SPI1 Flash读写、页擦除、循环存储，适配行车日志持久化。
•	lv_port_disp.c/h：SPI3屏幕底层移植，LVGL8.2适配，支持车载界面刷新。
•	系统时钟、I2C、SPI初始化：由STM32CubeMX一键生成，参数匹配本项目硬件。
九、代码逻辑与功能对应说明
•	车速功能：外部中断计数车轮脉冲，1s定时换算车速，自动判断超速并告警存日志。
•	姿态防撞功能：高频读取六轴数据，解算俯仰/横滚角，计算震动幅值，识别颠簸、碰撞、倾斜异常。
•	环境监测：1s周期采集温湿度，实时刷新车载界面。
•	分级告警：姿态轻微异常低频提示，超速/剧烈震动高频声光报警，区分故障等级。
•	数据存储：所有告警事件自动入队，任务异步写入Flash，不阻塞采集业务。
•	多任务架构：高优先级保障行车安全采集与告警，低优先级处理界面与存储，完全贴合车载实时性需求。
十、车载项目调试注意事项
•	电源抗干扰：车载12V电源波动大，必须搭配LC滤波、稳压模块，避免传感器数据跳变、系统重启。
•	中断防抖：霍尔车速脉冲增加软件去抖，避免电磁干扰导致脉冲误计数、车速虚高。
•	数据滤波：姿态、温湿度数据采用均值滤波，过滤车载高频电磁干扰，杜绝误告警。
•	Flash寿命保护：采用事件触发存储，非定时高频擦写，大幅降低Flash损耗。
•	任务优先级：禁止UI、存储任务抢占采集与告警任务，保证车载安全监测优先响应。
