# 硬件资料与实板适配

## 职责

连接软件接口与真实板卡，记录已经确认的资源和仍待冻结的接线参数。

## 资料索引

- [接口表](interfaces.csv)：设备、针脚、电压域、复用、驱动与访问接口。
- [通道表](channels.csv)：实际信号量程、单位、精度及采样要求。
- [实板清单](next-steps.md)：驱动适配与验收推进顺序。
- [SH3001探测](sh3001-probe.md)：板载IMU只读事件探测，不默认替代任务书MPU6050。

## 与软件的关系

真实驱动提供原始数据及有效性，采集处理器完成物理量转换，再进入统一快照。先核对芯片、驱动、量程和针脚，再接入 [Linux适配层](../../platform/linux/README.md)，算法和诊断无需因设备节点变化重写。

板端模拟运行、离屏图像与文件日志不等于真实外设通过。测试证据见 [报告](../reports/README.md)，接线前按实际板卡原理图完成接口冻结。
