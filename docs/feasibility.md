# 可行性评估 · 2026-10-20

结论：平台能力与软件路线具备可行性，可以开展框架开发；接口冻结、整机硬件可行性和性能达标尚未通过实板验证。

## 已核对依据

- 主任务书全文，根目录两份TXT、两份DOCX作为STM32背景参考；遍历整个目录，按源码/第三方库/二进制分类，抽查Makefile、入口、BSP、业务模块及依赖版本。未把数千个第三方文件逐行审计视为本阶段任务。
- 旧工程为STM32F407 Cortex-M4F、HAL、FreeRTOS、LwIP，使用arm-none-eabi工具链，迁移需重写设备层与系统层。
- 旧树LVGL宏实际为8.3.11，不能因文档写8.2便认定满足版本约束。
- 当前开发环境为Ubuntu x86_64、GCC9.4、CMake3.16.3；后续已找到实际SDK并完成交叉编译；板卡原理图及可连接板端仍缺失，见reports/sdk-validation.md。
- [官方底板资源](https://wiki.alientek.com/docs/Boards/Linux/DLRK3588/DLRK3588%20硬件参考手册/resource/1.1resource/)列有CAN、双千兆以太网、扩展IO与2个ADC输入、12V整板输入。针脚、电压和复用仍须依实际版本原理图冻结。
- [官方快速体验手册](https://wiki.alientek.com/docs/category/atk-dlrk3588-快速体验手册-1/)包含Buildroot烧写和功能测试，符合任务书的厂商镜像基线路线。

## 决定实施的路线

采用RK3588 Linux单主控，C++17/POSIX线程+CMake；厂商内核驱动优先，状态快照供诊断、GUI、网络各自读取。普通Linux不提供硬实时保证，所有时延与成功率必须实测。

## 需要先解除的阻塞

| 项目 | 缺少资料/验证 | 处理 |
|---|---|---|
| 板端ABI | SDK、工具链、镜像、libc | 探测后先跑交叉编译小程序 |
| 接口与供电 | 板卡版本、原理图、模块电压 | 接口冻结表逐项填写，禁止套STM32针脚 |
| SPI显示与触摸 | LCD/触摸芯片型号、驱动 | 验证fb/DRM及evdev，不默认换屏 |
| DHT11 | 内核IIO支持与实际采集成功率 | 2秒周期，30分钟成功率测量 |
| 霍尔 | 输出电压、峰值频率、PPR | 电气保护及峰值完整计数测试 |
| ADC | 通道数、量程、精度、采样率 | 两路引出不等于满足需求；评估外置ADC |
| W25Q128 | SPI复用、MTD分区、擦除几何 | 独立日志区、CRC与断电恢复验证 |
| 并发与时延 | 真实驱动负载 | P95、最大时延和24小时台架测试 |
