# 第5阶段软件验证：LVGL界面

日期：2026-10-20。测试为主机真实LVGL软件渲染、合成状态和SDL dummy后端；不属于实屏验收。

依赖：LVGL v8.2.0固定提交，中文裁剪字体随项目保存，主机SDL2=2.0.10。

执行 `./scripts/check.sh`：10项CTest（前阶段8项，加gui、gui-runtime）。
执行 `./scripts/build_rk.sh`：ARM64业务程序、导出工具、LVGL与中文字体编译链接。

| 测试条件/操作 | 预期 | 实际 |
|---|---|---|
| 240×320五页真实渲染、检查截图 | 仪表/健康/节点/历史/设置全部可显示，无主要控件越屏 | 通过 |
| 模拟72.5km/h、温湿度、正负角度、ADC与DI | 数值与单位显示、中文可读 | 通过 |

页面截图见[预览](../previews/gui-pages.png)，由gui-tests生成PPM后拼接为PNG；预览使用合成夹具，明确标记SIM。未使用AI生成或重绘界面图片。

五页面由单一LVGL线程调用，主线程发布统一快照。GUI设置使用独立队列和写入线程；确认请求由诊断线程处理。界面历史只显示有界最近窗口，完整历史可用前阶段工具导出。

限制：500次自动切页是加速软件交互测试，不等同于30分钟真实屏幕交互；未测试实际LCD/触摸驱动、板端HDMI、SPI刷新速率和长时间稳定性。未对现有视觉应用占用的显示或摄像头执行操作。真实显示flush及输入驱动留待板端适配。
