# 构建、探测与打包脚本

## 职责

把重复操作固化为入口；执行位置分为Ubuntu开发主机和RK3588板端。

## 工具索引

| 脚本 | 位置 | 用途 |
|---|---|---|
| check.sh | 主机 | CMake构建并运行CTest |
| build_rk.sh | 主机 | 使用厂商SDK交叉编译ARM64应用 |
| package.py | 主机 | 重新构建、收集部署文件并生成清单与校验包 |
| board_probe.sh | 板端 | 只读收集系统、设备及驱动信息 |

## 推荐流程

主机检查 → ARM64构建 → 打包 → 上传 → 板端运行 → 取回证据。`board_probe.sh`输出资源信息，不证明传感器可正常采样；上传与启动方法见 [部署说明](../deploy/README.md)。

构建产物放 `build/`、`build-rk/`，联调证据及交付包放 `out/`，不作为源码提交。
